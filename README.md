# Team Task Manager

This is a simple full-stack web application for managing team tasks.  
It helps users create, assign, and track tasks easily.

---

## Features

- User login and signup
- Admin and member roles
- Create and assign tasks
- Update task status (Pending, In Progress, Completed)
- View team members and their task status
- Simple dashboard for admin and members

---

## Tech Stack

**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express  
**Database:** MongoDB
